# Predição do Desempenho no ENEM 2024 com Indicadores Socioeconômicos

Projeto de TCC em Ciência de Dados voltado à análise e modelagem do desempenho no ENEM 2024 em nível municipal no estado de São Paulo, utilizando indicadores socioeconômicos.

## 📌 Objetivo

O objetivo deste projeto é investigar a relação entre indicadores socioeconômicos municipais — como IDH, renda per capita, alfabetização e acesso ao ensino superior — e o desempenho médio no ENEM 2024.

O projeto inclui:

- análise exploratória dos dados;
- integração de bases externas;
- modelagem preditiva;
- avaliação estatística;
- visualizações gráficas;
- interpretabilidade do modelo.
